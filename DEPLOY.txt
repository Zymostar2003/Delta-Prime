CEOSKIT SIGNAL ENGINE — VERCEL DEPLOYMENT GUIDE
================================================

WHAT YOU NEED
-------------
- A GitHub account
- Node.js installed (check: node -v)
- The project folder: ceoskit-signal-engine/

STEP 1 — CREATE GITHUB REPO
-----------------------------
Go to https://github.com/new
  Name:    ceoskit-signal-engine
  Visibility: Public or Private
  DO NOT tick "Add README" (we have one)
  Click: Create repository

STEP 2 — PUSH FROM TERMINAL
-----------------------------
Run these commands one by one:

  cd ceoskit-signal-engine

  git init
  git add .
  git commit -m "Initial deploy — CEOSkit Signal Engine"
  git branch -M main
  git remote add origin https://github.com/YOUR_USERNAME/ceoskit-signal-engine.git
  git push -u origin main

Replace YOUR_USERNAME with your actual GitHub username.

STEP 3 — INSTALL VERCEL CLI
-----------------------------
  npm install -g vercel

STEP 4 — LOGIN TO VERCEL
--------------------------
  vercel login

Choose "Continue with GitHub" — it opens a browser to confirm.

STEP 5 — DEPLOY
----------------
From inside the project folder:

  vercel

Answer the prompts:
  Set up and deploy? → Y
  Which scope? → your account
  Link to existing project? → N
  Project name? → ceoskit-signal-engine (or Enter for default)
  Directory? → ./ (just press Enter)
  Want to override settings? → N

Vercel will give you a preview URL like:
  https://ceoskit-signal-engine-abc123.vercel.app

STEP 6 — DEPLOY TO PRODUCTION
-------------------------------
  vercel --prod

You'll get your live URL:
  https://ceoskit-signal-engine.vercel.app

STEP 7 — LINK GITHUB FOR AUTO-DEPLOY
--------------------------------------
Go to https://vercel.com/dashboard
  → Your project → Settings → Git
  → Connect GitHub repo

Now every git push automatically redeploys.

STEP 8 — SET YOUR DERIV REDIRECT URI
--------------------------------------
Go to https://developers.deriv.com
  → Your OAuth app → Edit
  → Add redirect URI: https://ceoskit-signal-engine.vercel.app
  → Save

STEP 9 — CONFIGURE THE APP
----------------------------
Open your live URL in browser.
Tap ⚙️ API Settings (on login screen).
Fill in:
  App ID:          (from developers.deriv.com)
  OAuth Client ID: (from developers.deriv.com)
  Redirect URI:    https://ceoskit-signal-engine.vercel.app
Tap 💾 Save & Apply.
Tap → Login with Deriv.

FUTURE UPDATES
--------------
Edit index.html locally, then:

  git add .
  git commit -m "your update message"
  git push origin main

Vercel auto-deploys in ~30 seconds.

Or force a manual redeploy:
  vercel --prod
